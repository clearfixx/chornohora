# Migration quality gate

The GitHub branch contains an asset-aware Next.js shell, not a finished native v22 scene.

Run locally:

```powershell
pnpm install
pnpm lint
pnpm typecheck
pnpm test:journey
pnpm test:source
pnpm build
```

`test:source` verifies that the iframe is gated by the presence of `public/legacy/index.html`. If the original v22 files have been imported, it checks the original animation root and location anchors. `node scripts/audit-v22.mjs` additionally validates all required v22 assets and relative HTML/CSS references, and is **mandatory once the assets are present**.

The GitHub Actions workflow is intentionally gated by a committed `pnpm-lock.yaml`. The repository currently has no committed lockfile, so CI cannot pass until the lockfile generated by `pnpm install` is added. Do not claim the PR is green before a successful CI run.

## Release blockers

1. Original v22 asset bundle committed in `public/legacy`.
2. Full UA/EN localization of the actual landing page, not just the Next.js shell.
3. Native React scene migration and scroll / tree occlusion parity.
4. Browser screenshots and interaction tests across breakpoints.
5. Successful CI and reviewed PR.
