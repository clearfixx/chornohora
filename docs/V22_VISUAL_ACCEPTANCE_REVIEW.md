# v22 → native: visual acceptance review

Review date: 2026-11-19. Source: Chromium comparison artifacts from workflow run [44480397153](https://github.com/clearfixx/chornohora/actions/runs/44480397153).

## Method
- Original: canonical /uk or /en with v22 iframe.
- Native: same route with `?preview=native`.
- 1440×900 and 390×900, five scroll checkpoints, both locales.
- Captures generated by `scripts/test-v22-scroll-browser.mjs`.
- `scripts/compare-v22-pixels.py` produces per-scene RGB error and side-by-side contact sheets; rightmost 18 px excluded from pixel statistics to limit scrollbar artifacts.
- Continuous opacity/position samples around each location are checked by Chromium.

## Results
- 20/20 screenshot pairs generated and compared.
- Significant RGB pixel differences (max channel difference ≥24): **0.1–1.1%** across pairs.
- Desktop Ukrainian: **0.1–0.3%**; mobile Ukrainian: **0.1–1.1%**.
- Desktop English: **0.5%**; mobile English: **0.1–1.1%**.
- Original and native location titles are readable, horizontally centered within the scene and behind foreground mountain layers at sampled checkpoints.
- The strongest pixel discrepancies occur on the Hero, particularly mobile (1.1%). Difference maps show localized text/controls and animated detail discrepancies, not broad scene-layout shifts.

## Human visual review
Reviewed `contact-uk-1440.jpg` and `contact-uk-390.jpg` from the workflow artifact. Five scenes preserve the overall layout, mountain silhouettes, colors and composition in both implementations. Small localized differences are visible in controls, lettering and foreground details. This is not a proof of pixel-identical rendering at every scroll position.

## Release decision
**Do not switch the canonical route to native yet.** Static screenshot parity is strong but final acceptance still needs:
1. Real-time continuous scrolling at varying speeds, including rapid reverse scroll and touch gestures.
2. Manual keyboard and mobile navigation verification, not only scripted synthetic events.
3. Review of all four contact sheets (both locales, both widths), including full-resolution Hero differences.
4. Confirmation that remaining localized visual differences are acceptable.

The approved v22 iframe remains the default; native stays available on `?preview=native`. No changes to `main` until acceptance.
