# Чорногора — Illustrated Edition v10

Оновлено на основі v9. Мандрівник повернутий на рівень основ дерев (88px), а частина оригінальних дерев дублюється у передньому шарі **перед** мандрівником. Інші дерева залишаються **позаду** нього. Геометрія дерев не змінена. Обидва шари використовують той самий клас `tr` і прокручуються синхронно.

Горизонтальна позиція мандрівника використовує той самий діапазон маршруту (Говерла–Петрос), що й прогресбар. На Hero персонаж і навігація приховані, як у v9.

## Запуск

```powershell
npx --yes http-server . -p 8000 -c-1
```

Відкрити http://localhost:8000.

## Перевірити

- Мандрівник іде по нижньому краю дерев, а не над верхівками.
- Деякі дерева закривають персонажа, інші залишаються позаду.
- При скролі назад рух змінює напрямок разом із прогресом.
- Hero та інші сцени не змінені.


## v12 — Hero та картки локацій
- На Hero приховано обидва шари передніх дерев; вони плавно з’являються на маршруті. Гори та нижні хребти збережено.
- Відновлено hover/focus карток через делегування подій, незалежне від моменту монтування DCLogic.
- На сенсорних екранах перше натискання відкриває картку, повторне переходить до локації.
- Спливаюча картка залишається в окремому шарі над лісом.

## v20 — виправлення 3D-меню
Поворот високого `.track` спричиняв проєкційне спотворення і майже повністю приховував сцену. Тепер анімується лише sticky `.stage` висотою одного екрана; `.track` лишається незмінним для scroll-timeline. Панель справа, навігація, блокування прокрутки та клавіатурне керування збережені.
